### **eBay（Sydney）｜AI Agent 开发实习生｜2026.01 – 2026.05**

**项目简介：**参与跨境购物场景对话式 Agent 的 V1→V2 工程优化，面向多平台商品搜索与复杂购物需求，主要参与 Agent 执行链路、长对话上下文治理、商品检索及离线评测相关开发。

**技术栈：**Python、FastAPI、LangGraph、OpenSearch、Redis、PostgreSQL、WebSocket、Embedding

- **Agent 编排与执行治理：**参与多平台商品搜索链路重构，将适合独立执行的平台级检索任务从 Main Agent 中拆分为按需 Fork 的 SubAgent，负责子任务 dispatch、独立执行上下文、结果回传及异常处理；补充迭代上限、执行超时与循环终止机制，并通过异步 fan-out 并发执行多平台搜索，平均搜索链路耗时降低 **[待实测]%**。
    
- **Context 治理与用户偏好接入：**负责长对话场景下的上下文裁剪，对历史消息、近期对话窗口及大体积 Tool Result 进行保留、摘要与截断，减少无效上下文占用；同时参与用户偏好 Store 接入，将预算、品牌、材质及平台偏好等结构化信息持久化至 Redis/PostgreSQL，用于跨会话复用，长对话平均输入 Token 降低 **[待实测]%**。
    
- **商品检索与数据标准化：**参与多平台商品 Candidate Schema 适配，将不同数据源统一为商品标题、价格、属性、物流及平台来源等标准字段；协助优化基于 OpenSearch 的 BM25 与 Embedding 混合检索链路，并通过离线 Query Case 对复杂条件及跨语言场景下的召回效果进行评测，**Recall@K / NDCG@K 达到 [待实测]**。
    
- **Agent 评测与可观测性：**构建覆盖商品硬约束、Tool 调用顺序、循环收敛及最终回答质量的离线回归 Case，记录 Query、Tool Trace、Fork 深度、Candidates、Latency 与 Token 等执行指标；结合 Trace 定位重复搜索、约束丢失与异常终止问题，任务完成率由 **[待实测]% 提升至 [待实测]%**。
